# CNWB 中文叙事写作榜

大模型，离写好故事还有多远？

网站：https://llmstory.github.io/

本仓库公开网站首页、榜单汇总分数、可视化、32道创作题的要求与必要材料，以及当前榜单24组配置的767份模型作答。Grok 4.7缺少A13作品，页面保留缺项。

可从“题目与作品”按题阅读并切换模型，也可点击榜单中的模型名称逐题查看作品。默认榜单仍为DeepSeek与MiMo各占50%的平均排行。

不公开模型评语、评审历史、原始推理内容、内部开发记录、账户信息或传输日志。
